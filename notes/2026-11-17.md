# 开张：为什么每天记一篇

## 今天学了什么

- 用 git + GitHub 搭了一个「每天一篇 Markdown」的学习仓库。
- 日常只有两个动作：`new-note.cmd` 建今天的笔记，`publish.cmd` 提交并推送。

## 关键点 / 结论

- 笔记不追求完整，追求**当天留下痕迹**；实在写不动的日子，就记一个概念 + 一句自己的话。
- 文件名用日期开头（`2026-11-17.md`），排序天然按时间，翻旧笔记不用想。
- 标题和标签写在 frontmatter 里，README 里的目录由脚本自动生成，不用手维护。

## 代码或公式

```text
new-note.cmd      # 建今天的笔记，自动用编辑器打开
publish.cmd       # 刷新目录 + commit + push
```
